# ⛏ ボクセルクラフト

ブラウザで遊べる、3Dのブロック掘り＆建築ゲームです。Three.js を使用しています。

## 🎮 プレイする

GitHub Pagesを有効にすると、次のURLで遊べます。

https://ferrarissound-design.github.io/bokusel/

**最初に一度だけ必要な設定:** このリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。その後、**Actions → Publish Voxel Craft → Run workflow** から初回デプロイを実行できます（以後は main の更新時に自動公開）。Pagesがすでに有効なら自動公開されます。

> 3DエンジンをCDNから読み込むため、最初の起動時にはインターネット接続が必要です。

## 遊び方

| PC | 操作 |
| --- | --- |
| WASD / マウス | 移動 / 視点変更 |
| Space | ジャンプ、飛行中は上昇 |
| Shift | ダッシュ、飛行中は下降 |
| 左クリック / 右クリック | ブロックの破壊 / 設置 |
| 1〜7 / マウスホイール | ブロック選択 |
| F / Esc | 飛行切替 / ポーズ |

**スマートフォン:** 左下スティックで移動し、画面右側の空いた場所をスワイプして視点を変更。右下の破壊・設置・飛行・ジャンプ・下降ボタンを使用します。画面下のホットバーでブロックを選べます。

地形は64×48×64、草・土・石・砂・原木・葉・板材の7種類。ブロックの編集はブラウザの localStorage に自動保存されます。タイトル画面の「ワールドを初期化する」でリセットできます。

## ファイル

- index.html: 完結したHTML・CSS・JavaScript
- .github/workflows/pages.yml: GitHub Pagesへの自動デプロイ

元コードの二重HTML、構文エラー、パーティクルマテリアルの管理問題などを修正し、スマホ操作と編集内容の保存を追加しています。
